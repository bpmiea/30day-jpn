# 管理后台

地址 `/admin/`。与学习应用共用账号和安全会话，只有数据库中 `role='admin'` 的启用账号可访问后台 API。注册和普通用户设置无法修改角色。

后台提供：

- 累计学习次数：`learning_events` 的幂等事件数，包括重做与复习；同一 event_id 重发只计一次。
- 累计学习时长、今日及近七天学习人数、达到 80% 的关卡数。
- 北京时间最近 14 天趋势与练习类型分布。
- 按邮箱/昵称搜索账号、分页和状态筛选。
- 停用/启用账号、注销全部登录。停用同时撤销会话，已有登录立即失效。

后台操作写入 `admin_audit`。管理员账号不能被停用，后台不提供密码读取或直接修改角色的入口。

新环境需要先应用 `0004_admin.sql`，然后在 D1 控制台或 Wrangler 中通过绑定的邮箱将指定**已注册账号**设置为管理员：

```sql
UPDATE users SET role='admin' WHERE email='your-registered-email@example.com';
```

不要创建公开的“成为管理员”接口，也不要将数据库管理权限发送到客户端。生产管理员已按用户指定的邮箱通过 D1 设置。
